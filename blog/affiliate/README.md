# 세꿀맛 제휴 마케팅 기준 (링크장인)

담당: 제휴 마케팅 : 링크장인 / 보고: 총 감독 : 블로그 자동화

## 1. 사용하는 제휴 프로그램
- 쿠팡 파트너스 (가입 완료)
- 네이버 쇼핑 커넥트 (가입 완료)

## 2. 링크 선택 기준
1. 같은 상품이면 최종 결제가(배송비 포함)가 더 싼 쪽을 우선한다.
2. 가격이 비슷하면(차이 3% 이내) 수수료율이 높은 쪽을 쓴다.
3. 품절, 판매 중지, 리뷰 평점 4.0 미만 상품은 넣지 않는다.
4. 가격과 재고는 발행 직전에 다시 확인하고, 확인 날짜를 표에 남긴다.

## 3. 대가성 문구 (필수)
제휴 링크가 하나라도 들어간 글은 본문 맨 위(첫 문단 안)와 링크 바로 근처에 아래 문구를 넣는다.

- 쿠팡 파트너스: `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`
- 네이버 쇼핑 커넥트: `이 포스팅은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.`
- 둘 다 쓴 글은 두 문구를 모두 넣는다.

## 4. 링크 관리 파일
- `blog/affiliate/links.csv`: 글별 제휴 링크 목록
- 열: 날짜, 글 제목, 상품명, 프로그램(쿠팡/네이버), 제휴 링크, 판매가, 확인일, 상태(사용중/품절/교체)

## 5. 작업 흐름
트렌드 리서치(촉촉이) 주제 → 링크장인 상품 조사·가격 비교·링크 생성 → 콘텐츠 작가(글꿀이) 원고 → 검수(꼼꼼이) 대가성 문구 확인 → 발행(올림이) → 성과 분석(숫자요정) 클릭·수익 피드백
