# 세꿀맛 제휴 마케팅 기준 (링크장인)

담당: 제휴 마케팅 : 링크장인 / 보고: 총 감독 : 블로그 자동화

## 1. 사용하는 제휴 프로그램
- 쿠팡 파트너스 (가입 완료)
- 네이버 쇼핑 커넥트 (가입 완료)

## 2. 링크 선택 기준
0. 상위 규칙은 NPJOA/seggulmat-blog-automation 의 docs/AI_AGENT_RULES.md 를 따른다. 본문이 직접 소개하는 상품만 넣고, 글당 1~3개는 상한이지 목표가 아니며, 링크 없는 글도 정상이다. 링크 발급 전에 엔팔좋아님 후보 승인을 받는다.
1. 같은 상품이면 최종 결제가(배송비 포함)가 더 싼 쪽을 우선한다.
2. 가격이 비슷하면(차이 3% 이내) 수수료율이 높은 쪽을 쓴다.
3. 품절, 판매 중지, 리뷰 평점 4.0 미만 상품은 넣지 않는다.
4. 가격과 재고는 발행 직전에 다시 확인하고, 확인 날짜를 표에 남긴다.

## 3. 대가성 문구 (필수)
제휴 링크가 하나라도 들어간 글은 본문 맨 위(첫 문단 안)와 링크 바로 근처에 아래 문구를 넣는다.

- 쿠팡 파트너스: `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`
- 네이버 쇼핑 커넥트: `이 포스팅은 네이버 쇼핑 커넥트 활동의 일환으로, 판매 발생 시 수수료를 제공받습니다.`
- 둘 다 쓴 글은 두 문구를 모두 넣는다.

## 4. 링크 관리 파일
- 글별 후보 제안: seggulmat-blog-automation 콘텐츠초안/C0NN_affiliate_candidates.md (상품명, 실제 발급 링크, 가격과 확인 시각 KST, 배송형태, 추천 이유와 본문 문장 인용, 대가성 문구)
