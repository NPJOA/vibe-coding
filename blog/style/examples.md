# 엔팔좋아 문체 few-shot 예시 (examples.md)

원문에서 그대로 발췌했습니다(수정 없음). `[이미지]`는 사진, `[구분선]`은 구분선, `[인용구]`는 인용구 블록(` / `는 인용구 안 줄바꿈), `[링크카드]`는 링크 미리보기입니다. 연속된 `[이미지]`는 1개로 줄였고, 빈 줄은 원문 리듬을 보여 주려고 남겼습니다.

새 글을 쓸 때는 **같은 시리즈의 2026년 예시(6~10번)**를 우선 참고하세요. 1~4번은 과거 스타일 참고용입니다.
